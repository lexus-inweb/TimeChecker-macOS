# Time Checker для macOS

Автоматический учёт времени по проектам для ежедневного отчёта. Живёт в строке меню, раз в секунду смотрит
активное окно и к вечеру собирает отчёт: проект, время с округлением до 5 минут и черновик комментария.
Отчёт копируется одной кнопкой.

Это порт идеи [Bison Time Checker](https://github.com/iEuegene/Bison-Time-Checker) (Windows) под Mac.

**[⬇ Скачать последнюю версию](../../releases/latest)** · macOS 15+ · Apple Silicon и Intel

## Как работает
- Раз в секунду читает активное приложение, заголовок окна, а в Chrome, Safari, Arc, Brave, Edge, Vivaldi и Opera ещё и **адрес вкладки**. В Windows-версии виден только заголовок, на Mac проект по домену определяется точнее.
- Раскладывает время по проектам по правилам. Для каждого проекта задаются домены (`ti.ua` ловит и поддомены), фразы из заголовка или адреса и приложения целиком.
- **Простой:** если 3 минуты (настраивается) не трогать клавиатуру и мышь, время уходит в «Простой», начиная с последнего действия. Блокировка экрана и сон записываются как «Отлучки». И то и другое видно и при необходимости относится к проекту: например, читал документ или был на созвоне.
- Всё, что не попало в проект, лежит во вкладке **«Другое»** с группировкой по сессиям или по программам. Записи переносятся в проект по одной или пачкой. Правый клик → «Всегда относить сайт…» создаёт правило на будущее.
- **Дашборд** за день, неделю и месяц: время на проекты и вне их, график по дням, топ программ и сайтов.

Работает без AI и без облака. Данные лежат только на твоём Mac, в `~/Library/Application Support/TimeChecker/`, и никуда не отправляются.

## Установка
1. Скачай `TimeChecker-…-macos-universal.zip` из [Releases](../../releases/latest), распакуй и перетащи **Time Checker** в «Программы».
2. Первый запуск. Приложение не подписано сертификатом Apple, поэтому macOS его заблокирует. Открой «Системные настройки» → «Конфиденциальность и безопасность», прокрути вниз и нажми **«Всё равно открыть»**.
   Или одной командой в Терминале:
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Time Checker.app"
   ```
3. Дай доступы:
   - **Универсальный доступ** («Конфиденциальность и безопасность» → «Универсальный доступ» → включить Time Checker). Без него видно только приложение, без заголовка окна.
   - **Автоматизация.** При первом переключении в каждый браузер macOS спросит разрешение управлять им. Нажми «Разрешить», иначе адрес вкладки не читается.
4. В строке меню появятся часы. Нажми «Открыть…» → «Проекты» → «+» и заведи проекты и правила. В «Настройках» включи «Запускать при входе в систему».

## Отчёт
Время по проекту округляется до 5 минут (шаг настраивается). Комментарий собирается из самых «долгих» заголовков окон.
Его можно поправить, правка сохраняется. «Копировать отчёт» (⇧⌘C) кладёт в буфер весь отчёт одним текстом:

```
Техноїжак — 1 ч 25 мин
Аудит сайта; Техноїжак: план — Google Docs

Дизайн — 40 мин
Макет главной
```

## Ограничения
- Считается только активное окно в фокусе.
- Firefox не отдаёт адрес вкладки, для него работают только заголовки.
- Сервисы, в заголовке которых нет названия проекта (Serpstat, планировщики и т. п.), уходят в «Другое». Их нужно разобрать вручную или добавить правило с фразой.
- После обновления версии macOS иногда просит заново включить Time Checker в «Универсальном доступе».

## Сборка из исходников
Нужны только Command Line Tools (`xcode-select --install`), Xcode не обязателен.

```bash
./build.sh install
```

Скрипт прогоняет тесты, собирает `Time Checker.app`, кладёт его в «Программы» и запускает.

| Команда | Что делает |
|---|---|
| `./test.sh` | 60 тестов логики: домены, правила, округление, комментарии, группировки, трекер (простой, сон, блокировка, полночь), хранилище |
| `./build.sh` | сборка под текущую архитектуру в `build/` |
| `./build.sh install` | сборка, установка в `/Applications` и запуск |
| `./release.sh` | универсальный zip для GitHub Releases в `build/release/` |

Структура:
- `Sources/Core` — логика без AppKit: модели, правила, отчёт, трекер, хранилище. Покрыта тестами.
- `Sources/App` — сенсоры (Accessibility, AppleScript, idle), модель приложения и интерфейс на SwiftUI.
- `Tests/main.swift` — тест-раннер без XCTest.

Заметки:
- В новом SDK `@State` сделан макросом, а его плагин есть только в Xcode, поэтому в коде используется своя обёртка `@Local`.
- Подпись ad-hoc с требованием только по bundle id: разрешения macOS не сбрасываются при пересборке.
