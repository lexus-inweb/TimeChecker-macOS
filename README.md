# Time Checker для macOS

Автоматичний облік часу по проєктах для щоденного звіту. Живе в рядку меню, щосекунди дивиться на активне
вікно й надвечір збирає звіт: проєкт, час з округленням до 5 хвилин і чернетку коментаря.
Звіт копіюється однією кнопкою.

Це порт ідеї [Bison Time Checker](https://github.com/iEuegene/Bison-Time-Checker) (Windows) для Mac.

**[⬇ Завантажити останню версію](../../releases/latest)** · macOS 15+ · Apple Silicon та Intel

## Як працює
- Щосекунди читає активну програму, заголовок вікна, а в Chrome, Safari, Arc, Brave, Edge, Vivaldi та Opera ще й **адресу вкладки**. У Windows-версії видно лише заголовок, на Mac проєкт за доменом визначається точніше.
- Розкладає час по проєктах за правилами. Для кожного проєкту задаються домени (`ti.ua` ловить і піддомени), фрази із заголовка чи адреси та програми цілком.
- **Telegram.** Заголовок вікна Telegram завжди «Telegram @ акаунт» і не залежить від чату, тому трекер його не записує: за замовчуванням час у Telegram іде без заголовка. У «Налаштуваннях» можна ввімкнути **розпізнавання назви чату**: поки Telegram активний, Time Checker раз на кілька секунд знімає смугу з назвою чату й розпізнає текст на цьому Mac (ScreenCaptureKit + Vision). Заголовок стає «Telegram — назва чату», і правила-фрази розносять чати по проєктах.
- **Простій:** якщо 3 хвилини (налаштовується) не торкатися клавіатури й миші, час іде в «Простій», починаючи з останньої дії. Блокування екрана й сон записуються як «Відлучки». І те, і те видно, і за потреби його можна віднести до проєкту: наприклад, читав документ або був на дзвінку.
- Усе, що не потрапило в проєкт, лежить на вкладці **«Інше»** з групуванням за сесіями або за програмами. Записи переносяться в проєкт поштучно або пачкою. Правий клік → «Завжди відносити сайт…» створює правило на майбутнє.
- **Дашборд** за день, тиждень і місяць: час на проєкти й поза ними, графік по днях, топ програм і сайтів.

Працює без AI і без хмари. Дані зберігаються лише на твоєму Mac, у `~/Library/Application Support/TimeChecker/`, і нікуди не надсилаються.

## Встановлення
1. Завантаж `TimeChecker-…-macos-universal.zip` з [Releases](../../releases/latest), розпакуй і перетягни **Time Checker** у «Програми».
2. Перший запуск. Програма не підписана сертифікатом Apple, тому macOS її заблокує. Відкрий «Системні параметри» → «Конфіденційність і безпека», прокрути вниз і натисни **«Однаково відкрити»**.
   Або однією командою в Терміналі:
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Time Checker.app"
   ```
3. Надай доступи:
   - **Доступність** («Конфіденційність і безпека» → «Доступність» → увімкнути Time Checker). Без цього видно лише програму, без заголовка вікна.
   - **Автоматизація.** Під час першого переходу в кожен браузер macOS попросить дозвіл керувати ним. Натисни «Дозволити», інакше адреса вкладки не читається.
   - **Запис екрана** — лише якщо в «Налаштуваннях» увімкнено розпізнавання чату в Telegram. Після надання дозволу macOS попросить перезапустити Time Checker і час від часу перепитуватиме цей дозвіл.
4. У рядку меню з'явиться годинник. Натисни «Відкрити…» → «Проєкти» → «+» і створи проєкти та правила. У «Налаштуваннях» увімкни «Запускати під час входу в систему».

## Звіт
Час по проєкту округлюється до 5 хвилин (крок налаштовується). Коментар збирається з найтриваліших заголовків вікон.
Його можна виправити, правка зберігається. «Копіювати звіт» (⇧⌘C) кладе в буфер увесь звіт одним текстом:

```
Техноїжак — 1 год 25 хв
Аудит сайта; Техноїжак: план — Google Docs

Дизайн — 40 хв
Макет главной
```

## Обмеження
- Враховується лише активне вікно у фокусі.
- Firefox не віддає адресу вкладки, для нього працюють лише заголовки.
- Telegram не віддає назву відкритого чату через Accessibility: його інтерфейс закритий для цього API, а шапка чату просто малюється на екрані. Без розпізнавання чату весь Telegram — один рядок без заголовка, і правила-фрази його чати не розрізняють. Такі відрізки розбирай вручну або віднеси правилом «програма».
- З розпізнаванням назва чату іноді читається з помилками (емодзі зникають), а заголовок оновлюється через 1–3 секунди після зміни чату. Однакові на вигляд кирилиця й латиниця в правилах не розрізняються: фраза «CEO» спіймає і розпізнане «СЕО». Найперше розпізнавання після ввімкнення може тривати до хвилини: macOS один раз готує модель розпізнавання тексту. Перевірено на Telegram для macOS 13 (`ru.keepcoder.Telegram`), зокрема в повноекранному режимі; у Telegram Desktop (`org.telegram.desktop`) розмітка шапки може відрізнятися.
- Сервіси, у заголовку яких немає назви проєкту (Serpstat, планувальники тощо), потрапляють в «Інше». Їх треба розібрати вручну або додати правило з фразою.
- Після оновлення версії macOS іноді просить знову ввімкнути Time Checker у «Доступності».

## Збирання з вихідного коду
Потрібні лише Command Line Tools (`xcode-select --install`), Xcode не обов'язковий.

```bash
./build.sh install
```

Скрипт проганяє тести, збирає `Time Checker.app`, кладе його в «Програми» й запускає.

| Команда | Що робить |
|---|---|
| `./test.sh` | 126 тестів логіки: домени, правила, округлення, коментарі, групування, трекер (простій заднім числом, сон через кілька діб, пауза й північ, блокування), адреса вкладки, сховище, заголовок і шапка Telegram |
| `./build.sh` | збирання під поточну архітектуру в `build/` |
| `./build.sh install` | збирання, встановлення в `/Applications` і запуск |
| `./release.sh` | універсальний zip для GitHub Releases у `build/release/` |

Структура:
- `Sources/Core` — логіка без AppKit: моделі, правила, звіт, трекер, сховище. Покрита тестами.
- `Sources/App` — сенсори (Accessibility, AppleScript, idle, розпізнавання чату Telegram), модель програми та інтерфейс на SwiftUI.
- `Tests/main.swift` — тест-раннер без XCTest, `Tests/Regression.swift` — регресійні сценарії із зовнішнього код-рев'ю.

Нотатки:
- У новому SDK `@State` зроблено макросом, а його плагін є лише в Xcode, тому в коді використовується власна обгортка `@Local`.
- Підпис ad-hoc з вимогою лише за bundle id: дозволи macOS не скидаються під час перезбирання.
